# 千木电商 · 电商运营数据复盘表（免费样张）

给电商运营 / 店主用的每日复盘表：每天录入一行原始数据，看板自动算出点击率、转化率、客单价、净 GMV、退款率、投产比，并留出「结论区」逼自己写下判断和动作。

## 文件里有什么

- **参数**：三个预警线（退款率 / 投产比 / 点击率），全部是**示例参考值，可改**——不同类目差异很大，请按你自己的店改，别照抄。
- **使用说明**：口径说明与 3 步用法。
- **每日录入**：黄色格手填，前 3 行是虚构示例数据（仅供演示，可直接覆盖）。
- **复盘看板**：全自动计算，指标超过警戒线会自动提示。
- **复盘结论**：异常是什么、原因假设、明天验证什么、具体动作——复盘不是看数据，是做决定。

## 怎么用（3 步）

1. 在「每日录入」页填当天一行；
2. 打开「复盘看板」页看自动计算结果和异常提示；
3. 在「复盘结论」页写下异常、原因假设和明日动作。全程约 5 分钟。
